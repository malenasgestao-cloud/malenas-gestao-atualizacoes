# Malenas Gestão: atualizações

Aqui ficam só os **instaladores** de cada versão do Malenas Gestão, o sistema de caixa e gestão da loja
[Malenas Styles](https://www.malenasstyles.com.br).

O sistema instalado na loja procura versão nova aqui sozinho (ao abrir e a cada 6 horas), baixa sem atrapalhar
e avisa **"Versão nova pronta"**. Um clique em "Atualizar agora" e ele fecha e abre já atualizado.

- Nenhum dado da loja fica aqui: vendas, clientes e senhas ficam só no computador da loja e no backup dela.
- Para instalar à mão, baixe o `Malenas-Gestao-Setup-<versão>.exe` da versão mais recente em
  [Releases](../../releases/latest).
